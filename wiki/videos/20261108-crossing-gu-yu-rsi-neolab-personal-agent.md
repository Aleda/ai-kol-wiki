# 谷雨：RSI 可能是 NeoLab 的机会、Personal Agent 真的有用、创业要造灭火器还是砖头？（十字路口，2026-11-08）

## Highlights

- **RSI 反而可能是 NeoLab 的机会：当 AI 能自己写训练 infra 和 recipe 时，大厂积累的 infra 和流程会变成累赘。** 从零开始的团队可以随时丢掉、重来（[00:02:02]–[00:03:02]）。
- 大厂的创新者窘境很具体：明知某项新技术能提一两个点，也因为适配自家 infra 代价太大而不用（[00:03:02]）。
- **Computer Use 的"手"已经基本解决，剩下的是"脑"。** 难的不再是点对按钮，而是知道这家公司的事该怎么办（[00:04:04]–[00:05:05]）。
- 模型一升级，团队几个月搭的"多跑几次、挑出对的、封装成 skill"的可靠性 pipeline 就白干了（[00:06:08]）。
- **真正的长程不是一个任务做一周，而是一个会计从菜鸟变成老员工。** 所以他们的 benchmark 是 100 道题连着做、边做边学，测的是持续学习这种元能力，刷题本身没有意义（[00:07:09]–[00:09:10]、[00:12:13]）。
- **又一次 bitter lesson：数学不靠形式化验证、只靠 scaling 的 informal 推理就做成了。** 两年前他和很多人都认为必须有 Lean 这类形式系统提供信号（[00:13:13]–[00:14:16]）。
- 他公开说过"写 memory notes 做持续学习不靠谱"，被打脸了：它确实不是可靠的优化算法，但上限被模型能力抬高了；不过他观察到只有 Anthropic 和 OpenAI 做得好（[00:16:18]–[00:17:20]）。
- 学术会议体系在 2026 年到了崩塌的临界点：一个 AC 批次 16 篇里能拿得出手的一两篇，他一年半没投论文、半年没审稿；评估人更该看对谈和 research presentation（[00:17:20]–[00:19:21]）。
- 十年后教授的社会地位可能不如夜店男模：智力不再稀缺时，长相、身材和情绪价值更值钱，就像机械时代让体力贬值（[00:21:25]–[00:22:26]）。
- **学术团队创业最容易变成"拿着锤子找钉子"。** 学术只要技术自洽，创业还要和市场闭环（[00:25:26]–[00:27:28]）。
- **头着火的人不会等你的灭火器，手边有砖头就拍。** 他们发布标准太高，造出满意的灭火器之前，卖砖头的已经卖了一百块（[00:28:29]–[00:29:30]）。
- 创业成了随大流的事；国内有 NeoLab 直接拿到 20 亿美元估值，这让在硅谷拿 4000 万美元种子轮的他都震惊（[00:30:31]–[00:31:32]）。
- AI 电影到了能让人沉浸看两个小时的程度：B 站弹幕都在聊剧情，没人聊 AI（[00:32:34]–[00:34:35]）。
- Personal agent 起来不主要靠技术突破，而靠两个产品设计：一个持久的单一会话，像微信上和一个人聊天；以及拟人化（[00:35:37]–[00:37:39]）。
- 他的年度关键词预测：2024–25 是多模态，2025–26 是 coding，接下来到 2027 年下半年前是 continual learning；他还预测明年可能出现来自 RSI 创业公司的前沿模型（[00:38:39]–[00:39:39]）。

## 1. 创业公司做 RSI 为什么有机会

- 谷雨说上个月他还搞不懂为什么会有创业公司做 RSI，最近被打脸：两家 RSI 创业公司的发布让他意外，其中一家据他说一个人用三个多月训出的预训练模型比 K3 还强（[00:01:00]–[00:02:02]）。这是他的转述，没有给出评测细节。
- 他原来的逻辑：RSI 本质是模型叙事，要追前沿模型厂；而且递归要有起点，得先有自己的模型（[00:01:00]–[00:02:02]）。
- 改变的理由：AI 写训练 infra 和 training recipe 的能力会超过人，那时大公司积累的 infra 和 recipe 反而是累赘。他举国内某模型厂朋友的例子：大家都知道某项技术有用、能提一两个点，但要适配自家 infra 代价太大，所以不做；从零开始的创业公司没有这个负担，可以让 AI 搜一套新 recipe、搭一套新 infra，随时丢掉（[00:02:02]–[00:03:02]）。
- Koji 追问前提是否仍是要融到大量资金和算力。谷雨同意，因为走的是 full-stack 模型训练的叙事，那两家确实拿了很多钱（[00:03:02]–[00:04:04]）。

## 2. Computer Use：手解决了，剩下脑

- 他们团队做 computer use agent。他说去年大家讨论的是泛化和可靠性，到 2026 年初操作层面的问题基本解决了，主要原因是 coding 训练规模上去后泛化到了软件和网页操作（[00:04:04]–[00:05:05]）。
- 剩下的是认知层面：模型常常不知道一件事在这家公司该怎么处理，比如内部业务流程；一旦知道，操作没有问题（[00:05:05]）。
- 公司刚成立时花了几个月解决可靠性：让它做几次，挑出做对的，封装成可复用的 skill，搭了一套 pipeline；现在 Opus 5.5 自己实现这个流程很快，还会自己纠错（[00:06:08]）。

### Apprentice Bench：边干边学的 benchmark

- 他们发布的 Apprentice Bench 是建筑行业会计报账场景的 100 道题，每题涉及不同的公司惯例、特定工作流和审批流程（[00:06:08]–[00:07:09]）。
- 关键设计是 100 道题不是独立的，要按顺序连着做，前面题目得到的反馈和知识决定后面能否做对（[00:07:09]–[00:08:10]）。
- 他对长程任务的看法：现在不少长程 benchmark 偏向找"特别难、一个人要做半天"的任务，这类任务难找、难扩展；他认为长程的终局是 lifelong intelligence，真正的长程是一个会计从菜鸟变成公司老员工的几个月到一两年（[00:08:10]–[00:09:10]）。
- 他所在的 OSU NLP 组此前发过 MMMU、Mind2Web（2023-05）、Online-Mind2Web，并与清华合作过 AgentBench（[00:09:10]–[00:10:11]）。
- 他说目前第一版上 Claude 最强模型约 80 分，区分前沿与非前沿模型的维度是持续学习能力，关键数据是教模型写好 memory notes 的数据；他听说 OpenAI 和 Anthropic 各有 recipe，Claude Code、Codex 的长会话天然带这类数据（[00:10:11]–[00:11:11]）。新版本很快发布，最强模型分数会低很多（[00:11:11]）。
- 为什么难刷：测试集没有公开；而且测的是持续学习这种元能力，只把这家公司的会计做好没有意义，真要刷就得把元能力刷上去，那"也算积德"（[00:12:13]）。

## 3–4. 数学与 memory notes：两次被 scaling 打脸

- 他说 2024 年他认为数学能做成是因为有 Lean 这类形式化验证；结果数据量和质量上去后，2025 年已经能用 informal 方式拿 IMO 金牌，2026 年更进一步，很多前沿难题都被 informal 方式解决（[00:13:13]）。两年前觉得纯 informal 是 LLM"左脚踩右脚"，上限不高，"还是认知不足"，还是 bitter lesson（[00:13:13]–[00:14:16]）。
- 关于数学家的虚无感，他说理解：最聪明的一群人做对智力要求最高的事，智力突然不重要了。他猜数学以后可能像棋类一样，成为人挑战自己智力极限的活动（[00:14:16]–[00:15:17]）。Koji 插了一段拼豆自习室的见闻：按小时付费，每人一个格子安静地"劳作"（[00:15:17]）。
- 他 2026 年上半年到处讲"用写 memory notes 的方式做持续学习肯定不靠谱"，理由是改写 memory notes 不是可靠的优化算法、受限于模型自身能力；现在他认为模型越来越强后这条路的上限可观，但强调目前真正做得好的只有 Anthropic 和 OpenAI（[00:16:18]–[00:17:20]）。

## 5–6. 学术体系、PhD 与"教授与男模"

- 他认为 2026 年学术会议的评价、投稿和审稿体系到了临界点：大量 AI 生成的灌水论文，当 AC 时一批 16 篇能拿得出手的一两篇；他一年半没投论文，半年多没审稿也没当 AC（[00:17:20]–[00:18:20]）。
- 招人时他看对谈和 research presentation，认为逻辑表达和 QA 反应能体现综合能力（[00:18:20]–[00:19:21]）。他认为学术最好的评估是高水平的同行评议，比如院系 senior 教授听 job talk，而不是谁都能当审稿人的会议评审（[00:19:21]–[00:20:23]）。
- 他说中美学术圈都还在按惯性走，结果是 AI 方向毕业生当教职的优先级越来越靠后，原因是前沿实验室和 NeoLab 给的钱和资源多得多（[00:20:23]–[00:21:25]）。
- 他说十年后教授的社会地位可能不如夜店男模，而且"真的这么觉得"：人类历史上大部分时间体力更值钱，机械让体力贬值，AI 是数字世界的机械，脑力也会贬值；他认为短期内机器难以取代的是情绪价值，并举两种减肥药收入超过模型公司收入的说法（[00:21:25]–[00:22:26]）。这条收入对比是他的转述，节目里没有出处。
- 被问 PhD 还值不值得读，他不给建议："想读就读"，想做一件事就去做本身就是一种理性（[00:22:26]–[00:23:26]）。
- 他创业的原因：从没想过进大厂，受不了固定作息；要对方向有 ownership，很难为别人工作；对风险"没有任何概念"。Koji 问是否因为家庭给了安全感，他说父母对他没有世俗要求（[00:23:26]–[00:25:26]）。

## 7. 锤子找钉子，以及灭火器和砖头

- 他说他们组在苏煜带领下口碑好，靠的是 vision 和 taste：不拿锤子找钉子，从技术问题的根本出发；但创业后发现自己成了 "solutions in search of problems"（[00:25:26]–[00:26:27]）。
- 原因：学术只要在一套技术体系内自洽就行，创业还要和市场闭环，要想这个根本问题能为谁解决什么、带来什么商业价值；continual learning 是 AI 的根本问题，但放进产品该是什么形式，是他们过去一年交的学费（[00:26:27]–[00:27:28]）。
- 他引 YC 的说法：头着火的人不会等你递来一盆水或灭火器，手边有砖头就拍。他们发布标准太高，总要发一个自己满意、很 solid 的东西，而公司层面有时该先发不成熟的东西把闭环跑起来，"甚至先把牛吹出去都行"（[00:28:29]–[00:29:30]）。他认为马斯克是 fake it till you make it 的极致（[00:29:30]）。
- 对高中毕业甚至不读本科直接工作的趋势，他认为合理：教育资源丰富地区的人可以很早做真正有价值的事；但国内前十几年的教育更多在完成筛选，这条路不会大众化（[00:29:30]–[00:30:31]）。

## 8. 创业成了随大流

- 他说过去创业是非主流路径，这一年他频繁听到"大家都在创业、我也想创业"，觉得诡异（[00:30:31]）。
- 他的解释是钱多：他们 4000 万美元的种子轮在硅谷已算大，硅谷常见的种子轮是 500 万到 1000 万美元；他说 2026 年上半年国内有所谓 NeoLab 直接拿到 20 亿美元估值，让他震惊，他猜和房地产资金外溢有关但说自己不懂（[00:31:32]）。
- 他认为让最懂前沿技术的年轻人没压力地拿到资本是好事；"没压力"是因为多数不签回购和对赌，压力更多是会不会浪费几年时间（[00:31:32]–[00:32:34]）。

## 9–10. AI 电影与 Personal Agent

- 他说最近在 B 站看了一位 up 主用 AI 做的两个多小时僵尸片，"复活"了林正英，七八个角色的脸、衣着和情节前后一致；他是当电影在看，弹幕都在讨论剧情（[00:32:34]–[00:34:35]）。他认为最终大家不在乎东西怎么产生，只在乎交付物（[00:34:35]）。
- Koji 讲了朋友用 AI 写的科幻设定：人永生后算力越来越贵，要用自己的记忆换算力娱乐，因为模型进化还要吃人的记忆数据（[00:34:35]）。Koji 还说去年一部 60 集的 AI 短剧剧本报价约 7 万元人民币，现在 AI 一天能写一百个；他的粗暴结论是未来人只需要两件事，审美和美（[00:35:37]）。
- 谷雨认为 personal agent 起来更多是产品设计：一是持久的单一会话，不像 ChatGPT、Claude 按 session 开窗口，而像微信上一个对象一个窗口；二是拟人化，所以大家做卡通形象。他认为 proactiveness 不是新技术，scheduled task 早就能做（[00:35:37]–[00:37:39]）。
- 他自己用两个 personal agent，主要用来看邮件、挑重点推送；国内的外卖、订酒店服务接不上；他认为最终会收敛到一个（[00:37:39]–[00:38:39]）。

## 明年预测

- 年度关键词：2024–25 年是视觉语言和多模态，2025 年底到 2026 年是 coding，接下来到 2027 年下半年前是 continual learning，他认为对职业规划有参考意义（[00:38:39]–[00:39:39]）。
- 他"下一个预测、不是说一定发生"：明年可能出现来自 RSI 创业公司的最强模型，至少是前沿级别（[00:39:39]）。

## 与本库其他材料对照

以下对照是本库的编辑判断。

- **同系列第三期**：[赵晨阳](20261115-crossing-zhao-chenyang-kimi-accelerates-kimi-rsi.md)在下一期提到谷雨从 NLP 转做 agent，并说自己以前批评 agent 领域"礼崩乐坏"、后来"投降"（[赵晨阳期](20261115-crossing-zhao-chenyang-kimi-accelerates-kimi-rsi.md) [00:33:26]–[00:34:27]）。两人都把 Computer Use 的突破放进年度 Aha Moments，谷雨的结论是"手解决了、剩下脑"，赵晨阳讲的是推理侧为什么难（截图不能共享 KV cache 前缀）。两人也都把 RSI 放在第一条。
- **持续学习的两条路**：谷雨押注的是 memory notes 这类外置记忆，并承认其上限被模型能力抬高；[Sutton 与 Javed](20260818-training-data-sutton-javed-continual-learning-oak.md) 认为只改 context 不算学习，主张部署后更新权重（[Sutton 期](20260818-training-data-sutton-javed-continual-learning-oak.md) [00:22:09]）。两者对"真正的长程是边干边学"有共识，分歧在学到的东西放在哪里。
- **评估**：Apprentice Bench 要求按顺序做、靠前面的反馈学后面，是对赵晨阳"能评估的就能优化"的一个补充：持续学习本身也要先有能评估的形式，才谈得上被优化。
